Saelion, the Storeybrook creature, in Meta Daylight's inks: the five stages of the Saelion form (egg, kit, bun, sprite, saelion), asleep, and the bunny, tree octopus and butterfly pixie forms. These are reference renders with their colors baked in; in pages, draw it with `Storeybrook.creature(host, {form, stage, mood})` so it takes the current look's inks and breathes and blinks (see the Creature component).
